# Seven-minute research demonstration

**0:00–0:45 — Site and question.** Show a synthetic Indian campus with PV, battery, cooling, EVs and pumps. State that all values are illustrative and the name is provisional.

**0:45–1:30 — What the data support.** Open readiness report: full 15 minute trace supports retrospective testing; hide PV meter/SOC to show which claims become bounded or unknown.

**1:30–2:15 — Baseline and envelope.** Plot solar/load/grid import and a one-hour downward response envelope. Show asset contributions and why their independent maxima cannot simply be added.

**2:15–3:15 — Decision.** Compare no action, simple rule, and optimized schedule. Show one EV/pump/battery action, physical constraints, and paired baseline metrics with units.

**3:15–4:15 — Imperfect forecast.** Replay the same recommendation on cloudy/high-demand truth. Show service, peak, and feasibility; compare nominal and stress-safe response.

**4:15–5:15 — Minimum data test.** Aggregate to hourly and remove SOC/PV observations. Show overstatement/abstention and why a confident promise would be unsafe.

**5:15–6:15 — Measurement choice.** Add one measurement back and show how response interval width changes. Make no claim of universal minimum data from one run.

**6:15–7:00 — Report and limits.** Export the evidence report: assumptions, solver status, uncertainty method, negative results, next data to collect. Close with pilot path in shadow mode.

Demo guardrails: use a fixed seed and precomputed results, keep failures visible, never show fabricated model accuracy or real-world savings, and explain that feeder benefit is outside this site model.
