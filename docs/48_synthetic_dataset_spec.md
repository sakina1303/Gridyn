# Deterministic synthetic dataset specification

Each dataset has `dataset_id`, generator semantic version, canonical-model version, site/asset config hashes, weather/load scenario IDs, truth seed, observation seed, timestep, timezone, period and schema version. Serialize canonical sorted configuration before hashing. Do not use a global random generator: derive named streams from a root seed (`weather`, `load`, `EV`, `pump`, `HVAC`, `meter_noise`, `missingness`) so adding one process does not change others. Record library versions. Same config+seed+version must yield identical values and checksums on the supported runtime.

Truth generation order: local calendar and season → weather (irradiance/cloud/temperature) → available PV (zero in darkness, ≤AC cap) → critical and fixed load profiles → EV arrivals/departures/required energy → pump service/windows → HVAC occupancy/comfort or conservative availability → baseline valid schedules → optional candidate dispatch through simulator. Battery initial SOC and all constraints come from config, never sampled outside bounds. Tariff is a separate versioned economic input, synthetic unless linked to an applicable order. No number is presented as a measured campus fact.

Observation specification is an independent immutable transform: select visible meters/signals, aggregate interval kWh exactly before conversion to average kW, inject additive noise and multiplicative bias with units, flag outliers, remove isolated points or blocks, alter timestamp with explicit offset/duplicate/misalignment rules, and optionally omit asset metadata. Store corruption mask only in experiment artifact, not in analyst input. Truth and observed files have different IDs and access roles.

Include scenario families: clear/cloudy/monsoon-like solar, weekday/weekend load, high cooling, late EV arrival, pump restriction, low battery SOC, flat/synthetic ToD tariff, constrained export/import. These are archetypes, not calibrated Indian distributions. Every experiment persists exact configuration and dataset checksums; no hidden ad-hoc randomness.
