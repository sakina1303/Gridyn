# Research report schema

Versioned report fields: `report_id`, `schema_version`, `generated_at_utc`, `site_id`, `scenario_id`, `experiment_id?`, `baseline_run_id`, `run_ids`, `dataset_hashes`, `canonical_model_version`, `forecast_model_versions`, `optimizer_version`, `generator_version`, `tariff_id/version`, `timezone`, `interval_minutes`, `status`, `limitations`. Every numeric `MetricValue` includes value, unit, time window, baseline comparator, provenance (`synthetic/observed/inferred`), and calculation/run reference. No free-floating headline number.

Sections in order: executive summary with simulation/real-data label; site and period; data inventory/readiness and missingness; asset ratings and constraints; baseline definition; forecast performance and uncertainty method; up/down flexibility envelope by time and duration; tested reliability with N/source; optimization schedule/status/gap; paired scenario metrics and tradeoffs; failed/infeasible cases; structured recommended actions; ranked next measurements and burden; limitations and unsupported claims; reproducibility manifest. An operator version highlights actions and data needs, while a research appendix preserves formulas/configuration.

Render Markdown/JSON first. A PDF is later. Traceability check follows every displayed metric through report → run → scenario → model/solver → dataset/seed/version → interval values. Report generation must fail or mark a section unavailable if references or validation status are missing. Synthetic figures carry a visible label on every page/figure, not only a footnote.
