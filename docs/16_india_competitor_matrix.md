## What the comparison supports

- Generic scheduling, forecasting, battery control, and demand response are already served. They should not be claimed as inventions.
- Existing India pilots make pump shifting and transformer battery VPPs invalid as stand alone novelty claims.
- A possible opening is a **low data, uncertainty aware, operator explainable assessment and validation workflow** for smaller sites. This is a hypothesis requiring user interviews and an expanded product review. It is not a claim that these competitors lack it.
- Public descriptions rarely expose solver details, data access, API terms, tariffs, or rigorous outcome evaluation. Those fields remain unknown until documentation or interviews establish them.
