# Next best measurement method

Candidate measurements: 15 minute site import, PV output, battery SOC and AC power, EV session energy/departure, HVAC runtime and temperature/occupancy, pump run/tank level, tariff order/category, operator-approved asset constraints. “Measurement” may mean a meter, a data export, or one verified parameter; list setup and recurring burden separately.

**MVP choice: paired ablation sensitivity.** On synthetic truth datasets, hide one candidate input at a time, run the exact same assessment, then restore it while holding truth, seed, and other observations fixed. For candidate `m`, compute reduction in envelope overstatement `ΔO_m`, reduction in interval width `ΔW_m`, and reduction in decision regret or service failures `ΔR_m` across relevant events. Rank first by safety-critical `ΔO_m/ΔR_m`, then by normalized decision benefit per declared measurement burden. Do not collapse to one opaque scalar unless user-selected weights and units are shown. Prefer a Pareto table: impact, cost/burden, coverage, prerequisites, and evidence quality. Bootstrap across sites/seeds only when sample size permits.

At a real site without ground truth for unmeasured signals, label ranking **model sensitivity**, not observed information gain. Use one-at-a-time parameter bounds and hypothetical sensor accuracy to estimate which unknown drives the width of the feasible envelope; validate later after data collection. Interactions matter, so test top pairs. Value-of-information or Bayesian methods are post-MVP only if simple sensitivity fails to rank actionable measurements. The output says exactly which claim improves (“15 minute peak estimate” versus “battery discharge promise”) and which remains unknown.
