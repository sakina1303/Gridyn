# Minimum viable physical simulator

The simulator is a deterministic transition engine given `(config, truth disturbances, seed, schedule)`, not an optimizer. At each 15 minute step it reads available PV and gross uncontrollable demand, applies a candidate battery/EV/pump/HVAC schedule, updates battery and service states, computes grid import/export/curtailment from [46](46_canonical_model.md), and validates every bound. It refuses an infeasible schedule; it does not silently shed critical demand or create energy.

Minimum state: battery `E_t`; EV remaining kWh by session; pump remaining service (runtime/energy proxy initially); HVAC comfort state only if calibrated, otherwise approved scheduling window; prior power/on state for ramps/minimum run. Inputs: site grid limits, asset capacities/efficiencies/windows, 15 minute weather scenario, PV profile, critical and fixed load, tariff scenario (for cost only). Outputs: truth trajectories for all flows/states, service outcomes, balance residuals, and immutable provenance. A tariff cannot affect physics.

**Truth and observation separation:** generator produces complete exogenous truth (weather, available PV, uncontrolled demand, service obligations) and baseline realized trajectories. A separate observation operator maps historical/baseline truth to `ObservedDataset` using meter selection, missing intervals, aggregation to 30/60 min, noise/bias/outliers, and timestamp faults. Candidate strategy trajectories are replayed against the same exogenous truth for scoring; they are never given to the analyst as prior observations. Hidden truth is available solely to experiment scoring. This separation prevents information leakage in low-data experiments.

The first simulator does not solve AC power flow, thermal dynamics without calibration, battery chemistry, or grid outages unless explicitly configured. For an outage, zero import/export can make schedules infeasible; report that. It supports no-battery/no-PV/no-flex assets. Use a small hand-checkable two-interval fixture before stochastic profiles.
