# Response envelope algorithm

Input: a valid baseline trace, candidate window start `s`, duration `D` intervals, direction, asset constraints, shared site limits, and uncertainty set. Output is a table/cube `(s,D,direction,q_theoretical,q_technical,q_operational,q_tested_reliable,method,status)`, plus asset participation, recovery energy and binding constraints. `q` is **sustained kW throughout the window**; response energy is `qDΔ`. Use [46](46_canonical_model.md) for signs and balance.

For each `(s,D,direction)`, maximize scalar `q≥0` subject to one joint schedule over the response **and recovery horizon**. Down: `P_t≤P^0_t−q`; up: `P_t≥P^0_t+q`, all `t` in window. Bound `q` by site import/export ratings to avoid unboundedness. The theoretical pass uses only asset ratings/windows; technical adds SOC, energy, ramp, grid balance and connection; operational adds EV departure, pump service, comfort, critical load, operator permissions and terminal SOC. If any pass is infeasible, return status and no positive firm value. Binary on/off and direction decisions make this a small MILP; a safe upper bound or binary search over `q` is acceptable if independently verified.

Joint optimization prevents adding individual battery/EV/pump maxima that compete for the same PV, import cap, time, or service obligation. For attribution, remove each asset and recompute the envelope; label the resulting marginal difference as order-dependent, not a unique additive allocation. If objectives conflict, physical/service feasibility wins; cost is not part of the envelope definition. Report both up and down response and rebound after the window.

Tested reliability: hold the schedule or promised `q` fixed where it must be committed, replay across `N` documented truth scenarios, count cases satisfying response and all service constraints. Search largest `q` whose tested success fraction meets declared target `ρ` (e.g. 0.9 as a **study setting**, not field guarantee). Include binomial uncertainty where scenario sampling justifies it. If only hand-picked stresses exist, label `stress-set pass rate`, not statistical confidence; if distribution uncalibrated, `q_tested_reliable` is unknown. Response time is earliest interval after request when `q` can start, subject to asset delays; recovery time is first time all deferred service/SOC obligations return to baseline-admissible state.
